# C++ Algorithm Practice

C++ STL을 활용해 알고리즘 문제를 풀이하며 자료구조 선택, 시간 복잡도 분석과 경계 조건 처리를 연습한 기록입니다.

로컬 아카이브에는 638개 문제 번호에 대응하는 C/C++ 소스 643개가 보관되어 있습니다. 이 저장소에는 전체 아카이브를 그대로 옮기지 않고, 대표 알고리즘 중 풀이 과정을 설명하기 좋은 코드만 선별해 공개했습니다.

- 사용 언어: C++17
- 주요 활용: STL 컨테이너, 그래프 탐색, 동적 계획법, 그리디, 이분 탐색, 문자열 처리
